# Вычислительные системы, 121 группа

**Иванов Иван Иванович**, М3О-121СВ-26, вариант №3 (номер в списке 3).

Три программы на ассемблере RISC-V. Выполнялись и проверялись в симуляторе RARS.

* `task_a.asm` — считывает число и выводит 1, если оно равно 3, в противном случае выводит 0.
* `task_b.asm` — выводит все числа в диапазоне от min(x, 121) до max(x, 121) с шагом 3.
* `task_c.asm` — считывает введенные числа в массив из 19 элементов (16 + 3). Чтение останавливается, когда массив заполнен или когда пользователь вводит 0.

**Как запустить:**
1. Открыть нужный файл в RARS.
2. Нажать F3 (Assemble) для сборки.
3. Нажать F5 (Run) для запуска.
4. Вводить данные в появившемся окне Run I/O.
